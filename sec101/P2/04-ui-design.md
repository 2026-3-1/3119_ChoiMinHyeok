# sec101 - UI/UX 설계

## 디자인 컨셉: "Neon x Academy"

> 은은하게 퍼지는 네온 글로우 + class101의 강의 카드 레이아웃을 결합한 사이버보안 특화 강의 플랫폼
> 네온은 강조가 아닌 분위기로 — 배경 전체에 낮은 채도로 스며드는 느낌

## 페이지 구조

```
홈 (/)
├── 강의 목록 (/courses) .............. 검색 + 필터 + 카드 그리드
│   └── 강의 상세 (/courses/:slug)
│       └── 강의 수강 (/courses/:slug/learn)
│           └── 강의 영상 (/courses/:slug/learn/:lectureId)
├── 카테고리 (/categories) ............ 카테고리 카드 그리드
│   └── 카테고리별 강의 (/categories/:id)
├── 강사 (/instructors/:id) ........... 강사 프로필 + 강의 목록
│
├── 로그인 (/login)
├── 회원가입 (/register)
│
├── 내 수강 목록 (/my/courses) ........ 수강 중인 강의
├── 장바구니 (/cart)
├── 결제 (/checkout)
│
└── 관리자 (/admin) ................... 관리자 전용
    ├── 대시보드 (/admin/dashboard)
    ├── 사용자 관리 (/admin/users)
    ├── 강의 관리 (/admin/courses)
    └── 신고 관리 (/admin/reports)

강사 전용 (로그인 후 INSTRUCTOR 역할)
├── 내 강의 관리 (/instructor/courses)
│   ├── 강의 생성 (/instructor/courses/new)
│   └── 강의 편집 (/instructor/courses/:id/edit)
│       ├── 챕터 / 영상 관리
│       └── 자료 업로드
└── 수강생 관리 (/instructor/courses/:id/students)
```

## 핵심 인터랙션

| 요소 | 효과 |
|---|---|
| 히어로 배경 | `--glow-hero` radial-gradient — 넓고 은은한 그린 ambient |
| 강의 카드 호버 | `translateY(-4px)` + `--glow-hover` 은은한 그린 glow |
| 카드 기본 | `--glow-card` + `--border-subtle` 로 살짝 빛나는 테두리 |
| 검색 | 실시간 드롭다운 (debounce 300ms) |
| 진도 바 | 수강 완료 시 그린으로 채워지는 애니메이션 |
| 파일 업로드 | 드래그 앤 드롭 + 업로드 진행률 표시 |
| 난이도 배지 | 둥근 pill 형태, Easy/Medium/Hard 각 색상 |
| 버튼 호버 | 배경 밝기 살짝 올라가는 정도 — 과하지 않게 |
| 스크롤 | 페이드인 (Intersection Observer) |
