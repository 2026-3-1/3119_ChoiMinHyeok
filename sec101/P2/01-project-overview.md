# sec101 - 프로젝트 개요

## 프로젝트 비전 

sec101은 보안 초보자 보안 커뮤니티를 위한 강의를 서로에게 누구나 제공 가능한 강의 웹 서비스이다.

핵심은 여러 사람들이 수강자가 될수도, 강사가 될수도 있으며 지식을 공유할 수 있어야 한다.

---

## 핵심 가치
| 가치 | 설명 |
|---|---|
| 신뢰성 | 강사, 강사의 강의를 신뢰 가능 |
| 확장성 | 여러 분야 지원, 관리자 기능 |
| 정보성 | 정보의 깊이, 양질의 정보 제공 |
---
## 대상 사용자

### 수강생 (Student)
- 보안에 관심이 있는 사람
- 보안을 잘 못하는 사람
- 보안 커뮤니티에 관심 있는 사람
- 강사의 강의 또는 자료를 보고 평가, 공부

### 강사 (Teacher)
- 보안에 지식이 많고, 잘 가르치는 사람
- 보안 커뮤니티에 관심이 있는 사람
- 영상을 찍어 올릴수 있거나 좋은 자료 발견시 공유

### 관리자 (Admin)
- 강사가 믿을만 한지 판단
- 콘텐츠가 저작권이 없고, 믿을만 한지 판단
- 보안 지식이 많으며 관리 할 능력이 있는 사람

## 핵심 기능

### 수강생 기능
| ID | 기능 | 설명 |
|---|---|---|
| F1 | 수강 | 강의를 수강, 수강 취소 |
| F2 | 평가 | 평점 및 댓글, 대 댓글 추가 |
| F3 | 검색 | 분야별 강의, 강사 검색 기능 |
| F4 | 결제 | 강의 구매, 장바구니 CURD |
| F5 | 강의 신고 | 강의 저작권, 오류 지적 |
| F6 | 자료 시청 | 강사의 자료 시청 |
| F7 | 강사 평점 | 강사에 대한 평가, 피드백 |

### 강사 기능
| ID | 기능 | 설명 |
|---|---|---|
| I1 | 강의 업로드 | 유튜브 URL 또는 개인 영상 업로드/삭제, 가격 책정 |
| I2 | 수강생 관리 | 수강생 재제 |
| I3 | 자료 업로드 | 파일, 문서, 링크 추가/ 수정/삭제 |
| I4 | 평점 | 이 강사에 대한 평점 조회 |

### 관리자 기능
| ID | 기능 | 설명 |
|---|---|---|
| A1 | 사용자 관리 | 수강생/강사 삭제/제제 |
| A2 | 강의 관리 | 부적절한 강의 색출 및 제재/삭제 |
| A3 | 대시보드 | 강의 신고 조회, 강의 전체 통계 |
| A4 | 관리자 인증 | 로그인/로그아웃 |
