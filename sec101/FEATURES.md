# 기능 체크리스트

> 진도율 저장 / 다음 강의 자동 재생 / 강의 순서 잠금은 별도 항목으로 분리됨

---

## 인증 (Auth)

- [x] 회원가입 (이름 · 이메일 · 비밀번호)
- [x] 로그인 / 로그아웃
- [x] JWT Access Token 발급 (메모리 보관)
- [x] Refresh Token 쿠키 기반 자동 재발급
- [x] 새로고침 시 세션 복원 (localStorage + refresh 요청)

---

## 헤더 (SiteHeader)

- [x] 로고 클릭 → 메인 이동
- [x] 강의 목록 / 내 학습 링크
- [x] 로그인 상태별 버튼 분기 (로그인 전: 로그인·회원가입 / 후: 유저명·로그아웃)
- [x] 장바구니 아이콘 + 담긴 수량 뱃지
- [x] 스크롤 시 헤더 스타일 변경

---

## 메인 페이지 (MainPage)

- [x] 히어로 섹션 (카테고리 수 · 전체 코스 수 통계 표시)
- [x] 카테고리별 필터로 최신 강의 6개 표시
- [x] 전체 강의 보기 링크

---

## 강의 목록 페이지 (CoursePage)

- [x] 강의 카드 그리드 표시
- [x] 키워드 검색 (특수문자 필터링 · 100자 제한)
- [x] 카테고리 필터
- [x] 페이지네이션 (이전 / 다음)
- [x] 로딩 중 스켈레톤 UI

---

## 강의 상세 페이지 (CourseDetailPage)

- [x] 강의 정보 표시 (제목 · 설명 · 난이도 · 카테고리 · 썸네일)
- [x] 총 강의 수 · 총 재생 시간 표시
- [x] 챕터별 커리큘럼 아코디언
  - [x] 수강 중 또는 강사 본인: 강의 목록 링크 클릭 가능
  - [x] 미수강: 링크 없음 (잠금 표시)
- [x] 수강 여부에 따른 CTA 버튼 분기
  - [x] 미로그인 → "로그인하여 수강하기"
  - [x] 강사 본인 → "강의 보기"
  - [x] 수강 중 → "이어보기" (마지막 수강 위치로 이동)
  - [x] 장바구니 담김 → "장바구니 보기"
  - [x] 기본 → "장바구니 담기"


---

## 장바구니 페이지 (CartPage)

- [x] 장바구니 목록 조회
- [x] 아이템 체크박스 선택 / 해제
- [x] 아이템 로드 시 전체 자동 선택
- [x] 선택 항목 금액 합산 표시
- [x] 아이템 삭제
- [x] 데모 결제 (실제 과금 없음)
- [x] 결제 완료 후 수강 목록 / 수강 상태 캐시 갱신 → 강의 상세 버튼 즉시 반영

---

## 내 학습 페이지 (MyLearningPage)

- [x] 수강 중인 강의 카드 목록
- [x] 진도율 프로그레스 바 표시
- [x] 마지막 강의 있으면 "이어보기" / 없으면 "강의 시작하기" 버튼

---

## 강의 플레이어 (LecturePage)

- [x] YouTube 영상 임베드 재생 (`enablejsapi=1`)
- [x] 네이티브 `<video>` 재생 (YouTube URL 아닌 경우)
- [x] 이전 / 다음 강의 이동 버튼 (상단 바)
- [x] 현재 강의 제목 / 카테고리 표시 (상단 바)
- [x] 강의 정보 표시 (재생 시간 · 순서 · 공개 여부 · 원본 링크)
- [x] 챕터 커리큘럼 사이드바 (챕터 토글 열기/닫기)
- [x] 현재 강의 사이드바 하이라이트
---

## 미구현 / 작업 중

- [ ] 강의 완료 시 다음 강의 자동 재생
- [ ] 이전 강의 미완료 시 다음 강의 잠금
