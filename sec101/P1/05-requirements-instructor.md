# 요구사항 명세서 — 강사(Instructor) 기능

> **프로젝트**: SEC101 온라인 강의 플랫폼  
> **대상 역할**: INSTRUCTOR (강사)  
> **기준 스프린트**: P1 구현 완료 기준

---

## 1. 강사 인증 및 접근 제어

| ID | 요구사항 | 우선순위 | P1 상태 |
|----|----------|----------|---------|
| IA-01 | INSTRUCTOR 역할 계정만 강사 패널 접근 가능 | 필수 | ✅ 완료 |
| IA-02 | 미인증 또는 권한 없는 접근 시 차단 화면 표시 | 필수 | ✅ 완료 |
| IA-03 | 강사는 본인 강의만 수정/삭제 가능 (소유권 검증) | 필수 | ✅ 완료 |
| IA-04 | 헤더에 강사 전용 '강사 관리' 메뉴 표시 | 권장 | ✅ 완료 |

## 2. 강의 관리

| ID | 요구사항 | 우선순위 | P1 상태 |
|----|----------|----------|---------|
| IC-01 | 내 강의 목록 조회 (제목·난이도·가격·상태·수용인원·평점) | 필수 | ✅ 완료 |
| IC-02 | 새 강의 생성 (제목·설명·카테고리·난이도·가격·수용인원) | 필수 | ✅ 완료 |

| IC-06 | DRAFT ↔ OPEN 공개 상태 토글 버튼 | 필수 | ✅ 완료 |

| IC-08 | 강의 목록에서 상태 뱃지(초안/공개/비공개) 표시 | 권장 | ✅ 완료 |
| IC-09 | slug는 제목 기반으로 서버에서 자동 생성 | 권장 | ✅ 완료 |

## 7. 비기능 요구사항

| 항목 | 요구사항 |
|------|----------|
| 소유권 보호 | 모든 수정/삭제 API에서 강사 본인 강의인지 서버 검증 |
| 상태 관리 | DRAFT 강의는 공개 강의 목록 API에서 자동 제외 |
| 역할 제한 | 강사 계정은 장바구니·결제 기능 이용 불가 |
| UX | 삭제 시 2단계 확인(confirm) 처리로 실수 방지 |
