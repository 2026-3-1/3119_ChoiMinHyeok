# 요구사항 명세서 — 수강생(사용자) 기능

> **프로젝트**: SEC101 온라인 강의 플랫폼  
> **대상 역할**: STUDENT (수강생)  
> **기준 스프린트**: P1 구현 완료 기준

## 11. 비기능 요구사항

| 항목 | 요구사항 |
|------|----------|
| 보안 | JWT Access Token 메모리 보관, Refresh Token HttpOnly Cookie |
| 성능 | API 응답 300ms 이내 목표 |
| UX | 로딩 중 스켈레톤/스피너 표시 |
| 접근성 | 비로그인 상태 보호 라우트 접근 시 로그인 페이지 리다이렉트 |
| 역할 분리 | 강사 계정은 결제·장바구니 기능 비활성화 |
